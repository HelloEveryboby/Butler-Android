设计规范

色彩

纯白底色搭配 Apple 标准语义色。不使用渐变背景，不使用深色模式作为默认。颜色仅用于表达含义，不用于装饰。

#007aff Blue
#34c759 Green
#ff9f0a Orange
#ff3b30 Red
#af52de Purple

排版

  • Inter + Noto Sans SC — 系统级字体组合
  • 标题使用 700 weight，紧凑字距 -0.03em
  • 正文使用 400 weight，行高 1.45–1.65
  • 数字使用 tabular-nums 确保对齐
  • 标签使用大写 0.62rem + 0.08em 间距

组件

  • 卡片 — 20px 圆角，subtle shadow，无边框
  • 列表项 — 0.5px 分割线，13px 内边距
  • Toggle — iOS 原生样式，51×31px
  • Tab Bar — 毛玻璃背景，blur(20px)
  • Dynamic Island — 126×37px 黑色药丸
  • 聊天气泡 — 18px 圆角，蓝色/灰色区分

交互

  • 按压缩放 0.98 — 轻柔确认感
  • 消息气泡从下方滑入（200ms ease）
  • 思考指示器三点弹跳（1.4s）
  • Toggle 使用 cubic-bezier 弹性曲线
  • Tab 切换颜色渐变 150ms

导航

底部 5-Tab 标签栏，毛玻璃背景。活动 Tab 蓝色高亮。顶部使用 iOS 风格导航栏：居中标题 + 左右操作按钮。设置页使用分组列表（Grouped List）模式。

布局

  • 安全区：顶部 58px（状态栏），底部 84px（Tab Bar）
  • 内容边距：24px 水平内边距
  • 卡片间距：12px
  • Dynamic Island 居中，距顶部 12px
  • 聊天气泡最大宽度 78%
